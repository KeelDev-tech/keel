# Looking for a LazyApply alternative?

If you're leaving LazyApply, you're probably leaving for one of the
documented reasons: in Wired's test of the paid tier, it fired nearly 1,000
applications in one night for about 20 interviews — roughly a 0.5%
interview rate versus 10% manual — with answers that "seemed guessed"
(TechTimes). TrustPilot sits at 2.1 stars (via jobcopilot.com review).

## The free, open-source alternative

Keel is a free, open-source alternative to LazyApply — Apache-2.0, at
https://github.com/KeelDev-tech/keel — with one deliberate difference: it
refuses to do the things that made LazyApply fast. Keel's truthfulness
contract means it only ever claims what you tell it is true: verified
facts, a canonical answer bank, banded rules for gray areas, and hard gates
that stop the run when a question can't be answered honestly. It never
invents experience, degrees, or answers. It never submits an application —
the public loop stops at the launch packet. The private production
pipeline's ledger holds 55 verified submissions at launch, each confirmed
by the page itself.

## The honest trade

Keel will not fire 1,000 applications in a night. If volume is what you
want, Keel is the wrong tool on purpose. If you want automation that
refuses to lie — fewer applications, every one of them true — that's the
trade, stated plainly.
