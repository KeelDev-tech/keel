# Looking for an open-source auto-apply tool?

If you're searching for an open-source auto-apply tool, you've noticed
the gap: the auto-apply products are closed and paid — tiers from $99 on
some, around $80/month on others — while the open-source options rarely
handle the application pipeline at all. Keel fills that gap, and fills it
with a constraint the paid tools don't have: it refuses to lie on your
behalf.

## The open-source auto-apply tool that stops at the truth

Keel is an open-source auto-apply tool — open-core, Apache-2.0, at
https://github.com/KeelDev-tech/keel — built around a truthfulness
contract: it only ever claims what you tell it is true. Verified facts, a
canonical answer bank you write and it reuses verbatim, banded rules for
gray areas, and hard gates that park anything unmappable. It never invents
experience, degrees, or answers. It never submits an application — the
public loop stops at the launch packet. The private production pipeline's
ledger holds 55 verified submissions at launch, each confirmed by the page
itself.

## The honest trade

Keel will not fire hundreds of applications in a night. If volume is what
you want, Keel is the wrong tool on purpose. If you want automation that
refuses to lie — fewer applications, every one of them true — that's the
trade, stated plainly. Self host. Reclaim the time.
