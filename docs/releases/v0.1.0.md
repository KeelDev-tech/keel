# v0.1.0 — 2026-09-14

First public release of the Keel open-core job-application autopilot:
the job-application pipeline that refuses to lie.

## What this is

Keel is the public half of a real production pipeline: discovery → fit
scoring → truthful materials → answer bank → prescreen gates → ATS
detection → launch packets, with an honest-automation contract that is
load-bearing, not decorative. It only ever claims what the operator
tells it is true; hard requirements the profile can't support are
reported as gaps, never bridged with fiction.

## What's in it

The full list is in [CHANGELOG.md](../../CHANGELOG.md) under
`[0.1.0]`. Headline pieces:

- Discovery playbooks and sweep prompts; the 100-point fit model with a
  banded action policy (`engines/score_roles.py`).
- Truthful resume tailoring from the operator's verified profile,
  with truthfulness gates (`engines/resume_tailor.py`).
- Canonical answer bank with banded-question rules and hard gates —
  ships with example data only; real profiles are never committed
  (`engines/answer_bank.example.json`).
- Prescreen gates that park leads needing operator input instead of
  inventing answers (`engines/prescreen.py`).
- ATS detection and capability radar — identification plus HTTP-level
  probes of which submission paths are viable. Detection only, no
  submission behavior (`engines/ats.py`, `engines/edge_probe.py`).
- The apply loop, which builds launch packets and stops there per the
  open-core boundary (`engines/apply_loop.py`).
- Append-only telemetry, outcome analytics with fail-closed reporting
  rules, a pluggable employer-response listener, and a self-contained
  HTML dashboard (`engines/log_event.py`,
  `engines/outcome_analytics.py`, `engines/inbox_listener.py`,
  `engines/build_dashboard.py`).
- Setup wizard (`./setup.sh`) and stock config, so a fresh clone runs
  its first scored lead in minutes. Standard library only —
  Python 3.10+, no dependencies to install.

## What's verifiable

- **Public repo:** https://github.com/KeelDev-tech/keel — public,
  Apache-2.0 (see `LICENSE`).
- **Open-core boundary:** this release is the public half. The private
  execution layer (submission-behavior methods ATS vendors could
  fingerprint) is deliberately not published; the exact line is
  documented in [SPLIT.md](../../SPLIT.md).
- **Traction figure:** the private production pipeline that proved this
  discipline holds a ledger with **55 verified submissions at launch**.
  The public repo itself makes no submission claims — it is the tools,
  the gates, and the telemetry.
- **No projections.** Nothing here extrapolates; the 55 is a ledger
  count with explicit confirmation evidence behind it, not a rate,
  window, or forecast.

## How to get it

```bash
git clone https://github.com/KeelDev-tech/keel
cd keel
./setup.sh      # "Make it mine" — personalizes your working copy
./start.sh      # status overview
```

Then follow the quickstart in the [README](../../README.md).
