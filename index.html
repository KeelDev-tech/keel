The Contract

The truthfulness contract, as engineering.

Keel only ever claims what you tell it is true: verified facts, a canonical answer bank, banded rules for gray areas, and hard gates that stop the run when a question can't be answered honestly.

  1. 01
    Truthfulness gates
    Never invents experience, degrees, or answers. Required questions it cannot answer truthfully park the lead — they are never guessed.
  2. 02
    Explicit confirmation
    Nothing counts as submitted unless the page itself confirms it. A task accepted is not a submission.
  3. 03
    Fail closed
    Ambiguity parks the lead and moves on. The system would rather skip a real opportunity than file a dishonest one.

Every event — discovery, verification, gates encountered and cleared, submissions, outcomes — lands in an append-only telemetry log. The log is never rewritten; analysis reads it, never edits it. That is how the system improves without ever improving its story.
